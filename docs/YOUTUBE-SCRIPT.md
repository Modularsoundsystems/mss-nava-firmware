# YouTube script — MSS NAVA Firmware 1.0

Built for CapCut: each beat below is one clip + one text overlay. Import
clips in this order, trim to the marked duration, add the text in the
"On-screen text" column as a lower-third or centered card per CapCut's
default text tool. Target total runtime: **4:30–5:30**.

**Shooting notes (read before recording):**
- Record the NAVA's audio **direct out**, not room mic. The whole pitch is
  timing — a room mic blurs exactly what you're demonstrating.
- Camera on the panel, close enough to read the LCD and the step LEDs.
  A second angle (wide, hands-on-panel) is optional but helps cut 6 & 8.
- Actually perform every chord listed under "Demonstrate" — don't mime it.
  If a chord doesn't land the first take, that's fine, just cut around it.
- Shoot beat 1 (the jam) LAST, after you've warmed up on the rest — it's
  the section that has to feel natural, not rehearsed.
